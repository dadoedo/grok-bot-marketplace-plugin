How XBots works

Two feeds · zero fake APIs

01

Marketplace catalog

List, search, and compare the public SSR catalog at x.ai/bot/marketplace. Cards keep name, creatorName, summary, color, shape, and S3 imageUrl.

02

X viral feed

Recent search for marketplace URLs and grokbot:// shares. --demo works offline. Live search uses your Bearer token.

03

You tap Add

Agents return addHref and marketplaceUrl. There is no install API. Open the deep link in Grok Bot, or the marketplace page.

CLI for agents

skills/grok-bot-marketplace · skills/grok-bot-x-feed

plugin root
# Official catalog
python3 scripts/catalog.py search "outbound" --format text
python3 scripts/catalog.py compare researchy tinkabot

# X feed — fixture, no key
python3 scripts/catalog.py x-viral --demo --format text

# Live recent search
python3 scripts/catalog.py x-search --live --format text

X setup

App-only Bearer · never committed

  1. Create a Project + App at developer.x.com.
  2. Copy the Bearer Token (not the API key).
  3. cp .env.example .env and set X_BEARER_TOKEN.
  4. python3 scripts/catalog.py x-viral --live
