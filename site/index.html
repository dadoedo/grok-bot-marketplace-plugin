What you actually get

No partnership claims · MIT

Official marketplace catalog

List, search, compare, and refresh from the public SSR page at x.ai/bot/marketplace plus a checked-in data/catalog.json. Every card returns name, creator, description, categories, addHref, and marketplaceUrl.

X viral feed

Recent search for marketplace URLs, listing links, and grokbot:// shares. x-viral ranks by engagement.

Offline demo before the key lands

--demo or X_DEMO=1 reads a fixture. Missing Bearer token falls back the same way. CI never needs X credentials.

Secrets stay in env

App-only X_BEARER_TOKEN (or TWITTER_BEARER_TOKEN) from the environment or a gitignored .env. Tokens are never logged or written to the catalog.

Install is a link. Full stop.

There is no public Bot marketplace REST API. This plugin will not invent one. Open addHref in Grok Bot, or open the marketplace URL in a browser.

How it works

Three steps · no backend of ours

01

Snapshot the catalog

Parse the public marketplace HTML. Skills and CLI read data/catalog.json offline. Refresh when you ask.

02

Watch X for shares

Live: X API v2 recent search with your Bearer token. Otherwise the demo fixture. Hits join to catalog cards when a slug matches.

03

You open the deep link

Agents return grokbot://app/v1/bot-template?id=… plus the x.ai bot page. You install. The plugin does not.

$ python3 scripts/catalog.py x-search --live --format text

X Bearer, when you have it

App-only · recent search · ~7 days

  1. Create a Project + App at developer.x.com.
  2. Copy the Bearer Token (not the API key/secret).
  3. cp .env.example .env and paste X_BEARER_TOKEN= — never commit .env.
  4. Run x-search --live or x-viral --live.
X_BEARER_TOKEN=your-token
# aliases: TWITTER_BEARER_TOKEN, X_API_BEARER_TOKEN
X_DEMO=1
