How XBots works

Two feeds · zero fake APIs

01

Marketplace catalog

List, search, and compare the public SSR catalog at x.ai/bot/marketplace. Cards keep name, creatorName, summary, color, shape, and S3 imageUrl.

02

X viral feed

Recent search for marketplace URLs and grokbot:// shares. Published on grokbots.store by hetzner-prod. You do not set a Bearer token.

03

You tap Add

Agents return addHref and marketplaceUrl. There is no install API. Open the deep link in Grok Bot, or the marketplace page.

CLI for agents

skills/grok-bot-marketplace · skills/grok-bot-x-feed

plugin root
# Hosted feed (no API key)
python3 scripts/catalog.py search "outbound" --format text
python3 scripts/catalog.py compare researchy tinkabot
python3 scripts/catalog.py x-viral --format text

# Offline snapshot
python3 scripts/catalog.py list --offline

Public feed

https://grokbots.store/feed.json

  1. Install the plugin (cursor.directory or a local symlink).
  2. CLI/skills fetch https://grokbots.store/feed.json.
  3. Override with GROKBOTS_FEED_URL if needed. --offline uses the bundled snapshot.
  4. Operators refresh the feed on hetzner-prod — you never set an X Bearer token.
GROKBOTS_FEED_URL=https://grokbots.store/feed.json
GROKBOTS_OFFLINE=1
